# Akhil Krishna R — Academic Website
Static GitHub Pages website. Black theme, procedural animated galaxy backgrounds, research pages, selected peer-reviewed publications, and locally hosted profile photograph. No build dependencies.

## Deploy
Push the contents to the `main` branch of `akhilkrishnar0/akhilkrishnar0.github.io`. GitHub Pages publishes `https://akhilkrishnar0.github.io/`.

## References
Research descriptions are based on the author's public research page, published A&A and MNRAS papers, and ASI 2026 abstract. Animated galaxies are schematic illustrations, not scientific observations.
